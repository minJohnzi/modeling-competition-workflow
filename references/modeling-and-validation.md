# Modeling and Validation

## 1. Convert the prompt into a decision model

对每个子问题先写清：

- 题型归属（机理仿真 / 运筹优化 / 统计预测 / 评价决策，或混合型）；
- 决策者、物理系统与研究目标；
- 可控决策变量或待估未知参数；
- 给定参数、初边值与观测数据；
- 系统状态及其演化规律；
- 硬约束、守恒律与软偏好；
- 需要输出的指标、官方填报表和决策建议；
- 结论成立的时间、空间和样本边界。

先识别系统真实瓶颈或主导机理，再选择模型。容量、功率、时间、几何空间、热平衡、预算或信息滞后等约束可能共同形成可行域，不能只分析名义边界。

## 2. Audit data before feature engineering

至少检查：

- 文件、工作表、字段、类型、量纲和单位；
- 主键唯一性、重复、缺失和非法值；
- 时间覆盖、时区、采样频率、连续性与断点；
- 类别全集和关系矩阵/拓扑连接覆盖；
- 守恒、单调性或几何/物理恒等关系；
- 不同表之间的键、单位和粒度匹配；
- 异常值是传感器/录入错误、极端工况还是有效物理边界；
- 官方数据与参考资料是否冲突。

保存可机器读取的数据审计结果。清洗规则必须可复现，并说明对样本量、分布和结论的影响。

## 3. Define metrics with a scope contract

每个指标附带五元组：

    (对象集合, 时空范围, 分母, 聚合方式, 单位)

样本级完成率、个体平均误差、时间窗利用率、累计总量、系统峰值与加权综合得分不能因名称相似而直接比较。加权指标明确权重；相对改善同时报告绝对量、基准分母和发生位置。

## 4. Build a credible model portfolio

### Simple baseline

选择容易解释、容易复算、能揭示最基本结构的策略或模型，例如：
- 运筹调度：先到先服务（FCFS）、贪心局部规则或无协同基准；
- 预测回归：季节性朴素（Seasonal Naive）、历史均值或线性/Ridge 基线；
- 机理仿真：稳态解析近似、常系数线性化模型；
- 评价决策：等权重加权或单一经典客观赋权法。

### Reasonable competitor

选择能体现领域常用思想或更强建模能力的方案（如经典启发式/元启发式、ARIMA/GBDT、高阶数值积分、AHP-TOPSIS）。它必须拥有公平输入、约束和评价口径，不能故意弱化。

### Main model

主模型应针对数据审计和机理分析发现的瓶颈增加必要机制。说明哪些改善来自新增信息、显式约束、机理耦合还是算法搜索。

### Diagnostic non-solution

允许越限的松弛上界、忽略耦合的理想解或未修复状态可用于揭示系统压力，但必须标为诊断基准，不得与可行决策解混称。

## 5. Keep mathematical roles separate

明确区分：

- 物理状态变量与守恒/动力学方程；
- 统计误差指标与残差项；
- 财务、碳排、风险或工时结算量；
- 精确优化目标函数；
- 启发式候选排序评分；
- 多属性综合评价得分；
- 论文汇报与政策决策指标。

一个含服务惩罚、正则项或主观权重的复合评分，不自动等于真实物理成本或财务收益。不同权重或参数定义下的目标值不应直接横向比较。

## 6. Design algorithms with explicit boundaries

对启发式、数值迭代或分解算法说明：

- 候选生成与预筛规则；
- 排序评分、归一化及量纲；
- 并列打破规则（Tie-breaking）；
- 状态更新与可行性修复/维护；
- 迭代改进、迟滞与回退机制；
- 随机性（记录种子）或确定性；
- 时间/空间复杂度、最坏规模和停止条件。

先估算直接精确求解（MILP/NLP/全枚举）或全精细网格的计算规模。若不可承受，保留全范围可行的主算法，并把精确求解或高保真校验用于独立选定的代表性窗口或算例。

## 7. Validate in layers

### Data and identity

- 主键集合与原始输入一致；
- 无虚构记录、静默丢行或重复计数；
- 输入 SHA-256 哈希一致；
- 参考资料或旧版本数字未混入正式结果。

### Time, space, and state

- 到达、执行、结算与边界节点索引一致；
- 跨时段/跨网格重叠处理正确；
- 初值（Carry-in）、边值与终端状态（Closure）闭合；
- 状态递推的时序先后无因果反转。

### Physics, conservation, and constraints

- 容量、预算、时间窗、互斥与几何防碰撞约束；
- 质量/能量/动量/流量守恒与上下界；
- 模型输出由**独立于主求解器的新代码路径**重算验证；
- 数值残差在预设容差内。

### Objective and accounting

- 分项成本、分项误差或分项得分可加总还原；
- 收益与代价方向正确（最大化 vs 最小化不混淆）；
- 样本范围、观测窗口与加权分母无遗漏。

### Comparative evidence

- 所有方案使用共同输入、相同切分和相同硬约束；
- 基线没有因实现缺陷或弱参数被不公平击败；
- 主模型不是只靠单一局部指标取胜；
- 运行时间、内存与求解成本被真实记录。

## 8. Use exact or lower-bound validation honestly

需要验证大规模优化或复杂近似解的质量时，独立选择验证窗口或代表算例，避免按主模型表现挑选“漂亮窗口”。固定窗外边界与 Carry-in，使精确模型覆盖启发式落点，报告：

- 验证窗口与独立选择规则；
- 固定对象与自由决策变量规模；
- 求解器名称、版本、时间限制与容差；
- incumbent、最优值或松弛下界/上界；
- 绝对和相对 gap；
- 该局部证据不能外推到的全局范围。

局部最优不能写成全时域最优；LP 松弛或对偶下界存在明显间隙时应明确说明。

## 9. Design sensitivity for decisions, not decoration

优先扰动会改变可行域、平衡点或排序决策的因素：

- 核心需求、载荷或边界激励强度；
- 容量、资源上限、截止时间与服务水平；
- 关键物理/工程参数（阻尼、导热率、传播速度、效率）；
- 价格、惩罚系数、折现率或风险权重；
- 多目标/多指标权重分布与正则化系数。

采用粗网格定位变化区，再用二分或局部加密识别**临界相变区间或拐点**。若敏感性曲线完全平坦：

1. 检查参数是否真正进入模型计算图；
2. 检查场景是否退化或对应约束始终不活跃；
3. 扩大扫描范围至跨过物理/经济临界点；
4. 更换更有决策解释力的扰动因素。

有限参数网格只称“离散候选”或“离散非支配集”，不得称为连续 Pareto 前沿。

## 10. Guard against degenerate improvements

当基线值接近零、分母极小或所有方案表现相同时：

- 保留原始主场景作为正式事实，不篡改输入掩盖现象；
- 同时报告绝对差值、基线分母和退化发生位置；
- 禁止用“降低 100%”或“无穷大提升”作为标题核心结论；
- 预先按物理和业务规则定义非退化压力情景，不按改善率挑情景；
- 解释退化来源于数据边界、约束未激活还是模型设定失配。

## 11. Select a recommendation

在硬约束可行的候选中综合权衡：

- 主要目标与核心误差规模；
- 极端误差、尾部风险或最坏工况；
- 迁移、等待、切换、硬件或政策执行代价；
- 参数与环境扰动下的稳定性；
- 可解释性、算法复杂度与工程可落地性。

删除明显被支配或完全退化的指标后再做多指标决策。推荐方案不是“每一项都最优”，而是在明确偏好、约束和适用边界下最可辩护的选择。

## 12. Archetype-specific validation matrix

根据每道子问题所属题型，在通用验证之外强制执行对应专属检查：

### Archetype I — 连续机理、几何与微分方程仿真（ODE / PDE / 物理工程）
- **量纲齐次性审计**：每个控制方程与边界条件逐项核对量纲，无隐蔽的单位倍率错误。
- **步长与网格收敛性测试（Grid/Step Independence）**：至少测试 3 组加密步长（如 $\Delta t, \Delta t/2, \Delta t/4$ 或网格加密），报告关键输出随步长加密的相对变化率，证明结果不是数值积分震荡或截断误差产物。
- **守恒律与物理极限校核**：核对总能量、质量、动量、几何闭合或相容性残差；在零输入、稳态、对称或小参数退化情形下与解析解/物理直觉交叉验证。
- **刚性与稳定性说明**：说明数值求解器选择理由（如显式 RK45 vs 隐式 Radau/BDF）及精度容差设置。

### Archetype II — 离散运筹、组合优化与调度（LP / MILP / 图论 / 启发式）
- **活跃约束与瓶颈识别**：明确哪些资源、时间窗或逻辑互斥约束真正绑定了最优解（对偶价格或松弛度为零）。
- **Solver 与 Verifier 代码分离**：必须用独立于优化求解器的验证脚本，从原始决策变量逐条重算所有硬约束与目标分量。
- **解质量与多初值稳定性**：对精确求解器报告 MIP gap 与求解状态；对元启发式（GA/PSO/SA/ALNS）必须报告多种子（如 $\ge 5$ 个独立种子）的均值、标准差、最优值与最差值。

### Archetype III — 统计学习、时序预测与故障诊断（ML / DL / 因果与反演）
- **无泄漏切分（Leakage-Free Split）**：时序数据严格按时间先后切分或滚动回测（Rolling/Expanding Window）；面板或分组数据按实体分组切分（GroupKFold）；预处理（归一化、PCA、特征选择、过采样）**严禁**在切分前对全集拟合。
- **不确定性量化（UQ）**：点预测必须附带预测区间（如分位数回归、Conformal Prediction 或 Bootstrap 置信区间），并报告区间覆盖率。
- **可解释性与因果边界**：提供 SHAP / 特征重要性或局部归因，严格区分“统计相关性/预测贡献”与“因果机制”，不把高特征权重直接写成因果结论。
- **不平衡与诊断指标全集**：分类/故障检测不得只报 Accuracy，须按需要补全 Precision、Recall、F1、PR-AUC、虚警率与检测延迟。

### Archetype IV — 多属性评价、博弈与政策决策（AHP / 熵权 / TOPSIS / DEA / 动力学）
- **指标共线性与冗余剔除**：赋权前检查指标间相关矩阵或 VIF，解释为何保留或合并高度共线指标，防止重复计权。
- **主客观赋权对比**：比较主观法（AHP/BWM，附一致性检验 $CR < 0.1$）、客观法（熵权/CRITIC）与组合赋权的差异。
- **权重扰动下的排名翻转率（Rank Reversal）测试**：对权重向量施加系统扰动（如 $\pm 10\%$–$30\%$ 或 Dirichlet 抽样），报告 Top-$K$ 排名保持率以及 Spearman's $\rho$ / Kendall's $\tau$ 相关系数。
- **评分到决策阈值转化**：将无量纲综合得分映射为可操作的分级标准、政策触发阈值或资源分配方案。
